Aplicación de escritorio desarrollada en **C#**, utilizando **Windows Forms**, **.NET 10** y **Oracle Database 19c**.

La aplicación permite realizar operaciones matemáticas básicas y almacenar cada operación realizada en una base de datos Oracle 19c.

---

## 📋 Características

* ➕ Suma
* ➖ Resta
* ✖️ Multiplicación
* ➗ División
* 🧹 Limpiar calculadora
* 💾 Guardar operaciones en Oracle
* 📋 Consultar historial
* 🗑️ Eliminar historial
* ⚠️ Validación de división por cero
* ⚠️ Manejo de errores de conexión
* 🖥️ Interfaz gráfica Windows Forms
* 🗄️ Oracle Database 19c
* 🔌 `Oracle.ManagedDataAccess`

# ⚠️ Configuración de Oracle

Es necesario modificar:

```csharp
User Id=SYSTEM;
Password=oracle;
Data Source=localhost:1521/XEPDB1;
```

de acuerdo con la instalación local de Oracle.

Por ejemplo, si utilizas:

```text
Usuario: SYSTEM
Password: 123456
Servicio: ORCL
```

la conexión sería:

```csharp
private const string ConnectionString =
    "User Id=SYSTEM;" +
    "Password=123456;" +
    "Data Source=localhost:1521/ORCL;";
```

Otro ejemplo:

```text
localhost:1521/XEPDB1
```

corresponde normalmente a una base de datos Oracle XE utilizando el servicio `XEPDB1`.

# 9. OperacionRepository.cs

```text

```

Crear:

```text
OperacionRepository.cs
```

Código completo:

```csharp
using System.Data;
using Oracle.ManagedDataAccess.Client;
using CalculadoraOracle.Data;
using CalculadoraOracle.Models;

namespace CalculadoraOracle.Repositories
{
    public class OperacionRepository
    {
        public void Insertar(Operacion operacion)
        {
            using OracleConnection connection = ConexionOracle.ObtenerConexion();

            connection.Open();

            string sql = @"
                INSERT INTO CALCULADORA_OPERACIONES
                (
                    NUMERO1,
                    OPERADOR,
                    NUMERO2,
                    RESULTADO
                )
                VALUES
                (
                    :numero1,
                    :operador,
                    :numero2,
                    :resultado
                )";

            using OracleCommand command = new OracleCommand(sql, connection);

            command.Parameters.Add(
                "numero1",
                OracleDbType.Decimal
            ).Value = operacion.Numero1;

            command.Parameters.Add(
                "operador",
                OracleDbType.Varchar2
            ).Value = operacion.Operador;

            command.Parameters.Add(
                "numero2",
                OracleDbType.Decimal
            ).Value = operacion.Numero2;

            command.Parameters.Add(
                "resultado",
                OracleDbType.Decimal
            ).Value = operacion.Resultado;

            command.ExecuteNonQuery();
        }

        public List<Operacion> ObtenerTodas()
        {
            List<Operacion> operaciones = new();

            using OracleConnection connection = ConexionOracle.ObtenerConexion();

            connection.Open();

            string sql = @"
                SELECT
                    ID,
                    NUMERO1,
                    OPERADOR,
                    NUMERO2,
                    RESULTADO,
                    FECHA_OPERACION
                FROM CALCULADORA_OPERACIONES
                ORDER BY ID DESC";

            using OracleCommand command = new OracleCommand(sql, connection);

            using OracleDataReader reader = command.ExecuteReader();

            while (reader.Read())
            {
                Operacion operacion = new Operacion
                {
                    Id = Convert.ToInt32(reader["ID"]),

                    Numero1 = Convert.ToDecimal(
                        reader["NUMERO1"]
                    ),

                    Operador = reader["OPERADOR"].ToString()
                        ?? string.Empty,

                    Numero2 = Convert.ToDecimal(
                        reader["NUMERO2"]
                    ),

                    Resultado = Convert.ToDecimal(
                        reader["RESULTADO"]
                    ),

                    FechaOperacion = Convert.ToDateTime(
                        reader["FECHA_OPERACION"]
                    )
                };

                operaciones.Add(operacion);
            }

            return operaciones;
        }

        public void EliminarTodas()
        {
            using OracleConnection connection = ConexionOracle.ObtenerConexion();

            connection.Open();

            string sql = @"
                DELETE FROM CALCULADORA_OPERACIONES";

            using OracleCommand command = new OracleCommand(
                sql,
                connection
            );

            command.ExecuteNonQuery();
        }
    }
}
```

Código completo:

```csharp
using System.Globalization;
using CalculadoraOracle.Models;
using CalculadoraOracle.Repositories;

namespace CalculadoraOracle.Forms
{
    public class FrmCalculadora : Form
    {
        private TextBox txtNumero1;
        private TextBox txtNumero2;
        private TextBox txtResultado;

        private ComboBox cmbOperador;

        private Button btnCalcular;
        private Button btnLimpiar;
        private Button btnHistorial;
        private Button btnEliminarHistorial;

        private DataGridView dgvHistorial;

        private readonly OperacionRepository repository;

        public FrmCalculadora()
        {
            repository = new OperacionRepository();

            InicializarFormulario();
        }

        private void InicializarFormulario()
        {
            Text = "Calculadora - Oracle 19c";

            Width = 900;
            Height = 650;

            StartPosition = FormStartPosition.CenterScreen;

            FormBorderStyle = FormBorderStyle.FixedSingle;

            MaximizeBox = false;

            BackColor = Color.White;

            CrearControles();
        }

        private void CrearControles()
        {
            Label lblTitulo = new Label
            {
                Text = "CALCULADORA ORACLE 19c",
                Font = new Font(
                    "Segoe UI",
                    20,
                    FontStyle.Bold
                ),
                AutoSize = true,
                Location = new Point(270, 25)
            };

            Controls.Add(lblTitulo);

            Label lblNumero1 = new Label
            {
                Text = "Número 1:",
                Font = new Font("Segoe UI", 11),
                AutoSize = true,
                Location = new Point(80, 100)
            };

            Controls.Add(lblNumero1);

            txtNumero1 = new TextBox
            {
                Width = 220,
                Font = new Font("Segoe UI", 12),
                Location = new Point(180, 95)
            };

            Controls.Add(txtNumero1);

            Label lblOperador = new Label
            {
                Text = "Operación:",
                Font = new Font("Segoe UI", 11),
                AutoSize = true,
                Location = new Point(80, 150)
            };

            Controls.Add(lblOperador);

            cmbOperador = new ComboBox
            {
                Width = 220,
                Font = new Font("Segoe UI", 12),
                Location = new Point(180, 145),
                DropDownStyle = ComboBoxStyle.DropDownList
            };

            cmbOperador.Items.Add("+");
            cmbOperador.Items.Add("-");
            cmbOperador.Items.Add("*");
            cmbOperador.Items.Add("/");

            cmbOperador.SelectedIndex = 0;

            Controls.Add(cmbOperador);

            Label lblNumero2 = new Label
            {
                Text = "Número 2:",
                Font = new Font("Segoe UI", 11),
                AutoSize = true,
                Location = new Point(80, 200)
            };

            Controls.Add(lblNumero2);

            txtNumero2 = new TextBox
            {
                Width = 220,
                Font = new Font("Segoe UI", 12),
                Location = new Point(180, 195)
            };

            Controls.Add(txtNumero2);

            Label lblResultado = new Label
            {
                Text = "Resultado:",
                Font = new Font(
                    "Segoe UI",
                    11,
                    FontStyle.Bold
                ),
                AutoSize = true,
                Location = new Point(80, 250)
            };

            Controls.Add(lblResultado);

            txtResultado = new TextBox
            {
                Width = 220,
                Font = new Font(
                    "Segoe UI",
                    12,
                    FontStyle.Bold
                ),
                Location = new Point(180, 245),
                ReadOnly = true
            };

            Controls.Add(txtResultado);

            btnCalcular = new Button
            {
                Text = "CALCULAR",
                Width = 120,
                Height = 40,
                Location = new Point(450, 95)
            };

            btnCalcular.Click += BtnCalcular_Click;

            Controls.Add(btnCalcular);

            btnLimpiar = new Button
            {
                Text = "LIMPIAR",
                Width = 120,
                Height = 40,
                Location = new Point(580, 95)
            };

            btnLimpiar.Click += BtnLimpiar_Click;

            Controls.Add(btnLimpiar);

            btnHistorial = new Button
            {
                Text = "ACTUALIZAR",
                Width = 120,
                Height = 40,
                Location = new Point(450, 145)
            };

            btnHistorial.Click += BtnHistorial_Click;

            Controls.Add(btnHistorial);

            {
                Text = "ELIMINAR HISTORIAL",
                Width = 250,

            btnEliminarHistorial.Click +=
                BtnEliminarHistorial_Click;

            Controls.Add(btnEliminarHistorial);

            dgvHistorial = new DataGridView
            {
                Location = new Point(50, 320),
                Width = 780,
                Height = 240,

                AutoSizeColumnsMode =
                    DataGridViewAutoSizeColumnsMode.Fill,

                ReadOnly = true,

                AllowUserToAddRows = false,

                SelectionMode =
                    DataGridViewSelectionMode.FullRowSelect
            };

            Controls.Add(dgvHistorial);

            CargarHistorial();
        }

        private void BtnCalcular_Click(
            object? sender,
            EventArgs e)
        {
            try
            {
                if (!decimal.TryParse(
                    txtNumero1.Text,
                    NumberStyles.Any,
                    CultureInfo.InvariantCulture,
                    out decimal numero1))
                {
                    MessageBox.Show(
                        "Ingrese correctamente el número 1.",
                        "Validación",
                        MessageBoxButtons.OK,
                        MessageBoxIcon.Warning
                    );

                    return;
                }

                if (!decimal.TryParse(
                    txtNumero2.Text,
                    NumberStyles.Any,
                    CultureInfo.InvariantCulture,
                    out decimal numero2))
                {
                    MessageBox.Show(
                        "Ingrese correctamente el número 2.",
                        "Validación",
                        MessageBoxButtons.OK,
                        MessageBoxIcon.Warning
                    );

                    return;
                }

                string operador =
                    cmbOperador.SelectedItem?.ToString()
                    ?? "+";

                decimal resultado;

                switch (operador)
                {
                    case "+":

                        resultado = numero1 + numero2;

                        break;

                    case "-":

                        resultado = numero1 - numero2;

                        break;

                    case "*":

                        resultado = numero1 * numero2;

                        break;

                    case "/":

                        if (numero2 == 0)
                        {
                            MessageBox.Show(
                                "No es posible dividir por cero.",
                                "Error",
                                MessageBoxButtons.OK,
                                MessageBoxIcon.Error
                            );

                            return;
                        }

                        resultado = numero1 / numero2;

                        break;

                    default:

                        MessageBox.Show(
                            "Operador no válido."
                        );

                        return;
                }

                txtResultado.Text =
                    resultado.ToString(
                        CultureInfo.InvariantCulture
                    );

                Operacion operacion = new Operacion
                {
                    Numero1 = numero1,
                    Operador = operador,
                    Numero2 = numero2,
                    Resultado = resultado
                };

                repository.Insertar(operacion);

                CargarHistorial();

                MessageBox.Show(
                    "Operación calculada y almacenada en Oracle.",
                    "Éxito",
                    MessageBoxButtons.OK,
                    MessageBoxIcon.Information
                );
            }
            catch (Exception ex)
            {
                MessageBox.Show(
                    "Ocurrió un error:\n\n" + ex.Message,
                    "Error",
                    MessageBoxButtons.OK,
                    MessageBoxIcon.Error
                );
            }
        }

        private void BtnLimpiar_Click(
            object? sender,
            EventArgs e)
        {
            txtNumero1.Clear();

            txtNumero2.Clear();

            txtResultado.Clear();

            cmbOperador.SelectedIndex = 0;

            txtNumero1.Focus();
        }

        private void BtnHistorial_Click(
            object? sender,
            EventArgs e)
        {
            CargarHistorial();
        }

        private void BtnEliminarHistorial_Click(
            object? sender,
            EventArgs e)
        {
            DialogResult respuesta =
                MessageBox.Show(
                    "¿Desea eliminar todo el historial?",
                    "Confirmar",
                    MessageBoxButtons.YesNo,
                    MessageBoxIcon.Question
                );

            if (respuesta != DialogResult.Yes)
            {
                return;
            }

            try
            {
                repository.EliminarTodas();

                CargarHistorial();

                MessageBox.Show(
                    "Historial eliminado correctamente.",
                    "Información",
                    MessageBoxButtons.OK,
                    MessageBoxIcon.Information
                );
            }
            catch (Exception ex)
            {
                MessageBox.Show(
                    "Error al eliminar el historial:\n\n"
                    + ex.Message,
                    "Error",
                    MessageBoxButtons.OK,
                    MessageBoxIcon.Error
                );
            }
        }

        private void CargarHistorial()
        {
            try
            {
                List<Operacion> operaciones =
                    repository.ObtenerTodas();

                dgvHistorial.DataSource = null;

                dgvHistorial.DataSource = operaciones;

                if (dgvHistorial.Columns.Count > 0)
                {
                    dgvHistorial.Columns["Id"]
                        .HeaderText = "ID";

                    dgvHistorial.Columns["Numero1"]
                        .HeaderText = "Número 1";

                    dgvHistorial.Columns["Operador"]
                        .HeaderText = "Operador";

                    dgvHistorial.Columns["Numero2"]
                        .HeaderText = "Número 2";

                    dgvHistorial.Columns["Resultado"]
                        .HeaderText = "Resultado";

                    dgvHistorial.Columns["FechaOperacion"]
                        .HeaderText = "Fecha";
                }
            }
            catch (Exception ex)
            {
                MessageBox.Show(
                    "No fue posible consultar Oracle.\n\n"
                    + ex.Message,
                    "Error de conexión",
                    MessageBoxButtons.OK,
                    MessageBoxIcon.Error
                );
            }
        }
    }
}
```

# 20. Funcionamiento

El flujo de una operación es:

```text
Usuario
   │
   ▼
Ingresa número 1
   │
   ▼
Selecciona operador
   │
   ▼
Ingresa número 2
   │
   ▼
Presiona CALCULAR
   │
   ▼
C# realiza operación
   │
   ▼
```
